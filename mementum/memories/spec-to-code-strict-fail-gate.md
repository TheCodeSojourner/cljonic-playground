💡 Strict spec-to-code traceability is now part of `make upsert-gate-strict` via `make traceability-spec-to-code`. The gate requires set-scoped Allium validation (`allium check specs` + `allium analyse specs`), a synchronized committed snapshot at `spec-to-code-traceability/spec-to-code-obligation-ids.snapshot.txt`, and test trace coverage for every obligation ID. Traced test blocks must include at least one `CHECK*` or `REQUIRE*` assertion. Update the snapshot with `make traceability-spec-to-code-update-snapshot` when intentional spec obligation changes occur.
