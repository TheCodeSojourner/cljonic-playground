💡 For AI upsert loops, `make lint` is most usable when it auto-runs formatting first and limits lint surface to project paths. Run `make format` (src/tests only) before lint checks, then run `clang-tidy` with project path filtering so diagnostics are shown only for `src/**` and `tests/**`. Suppress analyzer `note:` lines in loop output to keep signal high while preserving non-zero exits for real warnings/errors. This keeps loops deterministic: quiet pass output (`lint:ok`), actionable failures, and no third-party `_deps` noise.
