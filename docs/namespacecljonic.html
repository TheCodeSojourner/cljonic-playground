Detailed Description

The Core namespace provides the vast majority of cljonic functions. Many Core functions deal with Array, Range, Repeat, Set, and String, collections. The variety and capability of the Core functions provide much of the overall value of the cljonic functional style of programming.

count returns the number of logical elements in collection.

#include "cljonic-core.hpp"
using namespace cljonic;
int main() {
const auto empty = Vector<int, 4>{};
const auto populated = Vector{1, 2};
const auto n0 = count(empty); // 0
const auto n1 = count(populated); // 2
return (n0 == 0 && n1 == 2) ? 0 : 1;
}
