cljonic

cljonic is a header-only C++ library for embedded system developers who want to program in a functional style. It provides functions similar in name and behavior to Clojure.

To address its embedded system focus, cljonic does not use the heap or exceptions. It uses modern C++ features to protect, guide, and teach C++ developers, includes unit tests with nearly 100% coverage, and is designed to be efficiently maintained.

The motivation for cljonic comes from observations made about the pragmatic use of C++ for embedded system software development, the progression of the C++ language (e.g., C++11, C++14, C++17, C++20, C++23), and the counsel of software development "experts", in many different programming languages, that a functional programming style should be eagerly embraced by all developers.

Many embedded system C++ developers are not academic programming language experts with in-depth knowledge of every C++ feature, and many may not have time to follow the progression of the language. Rather, many embedded system C++ developers have strong hardware backgrounds, and know a pragmatic specific subset of C++ that is often sufficient to deliver reasonably good software in a predictable amount of time, though this is often not optimized for minimal long term cost of ownership.

Generally speaking, many C++ developers use a subset of the C programming language with some of C++'s Object Oriented capabilities. This begs a question:

Is there a pragmatic subset of Modern C++ that enables embedded system developers to produce higher-quality, more efficient, and more maintainable code?

Changes to C++ have provided valuable capabilities that are time consuming to master, hence it is both valuable to development organizations for their developers to use modern C++ capabilities, and too expensive to train all of their developers to be experts in their use. This, too, begs a question:

Can one or two embedded system software developers cost-effectively introduce modern C++ capabilities to the entire team?

In this post: 

https://www.gamedeveloper.com/programming/in-depth-functional-programming-in-c-

the author makes the following statements:

"A large fraction of the flaws in software development are due to programmers not fully understanding all the possible states their code may execute in. In a multithreaded environment, the lack of understanding and the resulting problems are greatly amplified, almost to the point of panic if you are paying attention. Programming in a functional style makes the state presented to your code explicit, which makes it much easier to reason about [(i.e., Fewer mistakes, and less debugging)], and, in a completely pure system, makes thread race conditions impossible."

"No matter what language you work in, programming in a functional style provides benefits. You should do it whenever it is convenient, and you should think hard about the decision when it isn't convenient."

cljonic is a header-only library that utilizes Modern C++ capabilities to provide a functional style C++ Clojure subset to embedded system developers, promotes the predictable development of higher quality code faster, and can be cost-effectively maintained over time.
