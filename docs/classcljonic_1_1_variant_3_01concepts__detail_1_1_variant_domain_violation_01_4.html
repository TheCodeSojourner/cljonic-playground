Detailed Description

Diagnostic specialization (REQ-DIAG-012): selected by the redirecting deduction guide below. A Variant's alternatives are never deducible from its constructor arguments, so every deduced Variant reaches this specialization, which turns the failed-deduction candidate list into one targeted message.
