Detailed Description

template<std::integral value_type = int>
class cljonic::Range< value_type >

Range is a bounded integer producer that represents a sequence from start up to but excluding end, advancing by step. The supported subset is intentionally limited to integral types with explicit defaulting and bounded materialization. value_type defaults to int, so Range{} is equivalent to Clojure's (range).
