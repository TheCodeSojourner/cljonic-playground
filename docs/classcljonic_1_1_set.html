Detailed Description

template<concepts::VectorElement T, std::size_t CapacityValue>
class cljonic::Set< T, CapacityValue >

Set is a fixed-capacity associative sequence collection backed by contiguous array storage with linear-scan lookup and copy-on-modify semantics.
