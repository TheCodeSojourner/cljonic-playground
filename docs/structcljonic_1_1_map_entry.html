Detailed Description

template<concepts::NothrowStableEqualityComparable KeyType, concepts::NothrowCollectionElement ValueType>
struct cljonic::MapEntry< KeyType, ValueType >

A MapEntry is a value-semantic pair representing a single key-value association. Its fields are public, but MapEntry is not a C++ aggregate.

Use the map_entry factory as the idiomatic creation surface at runtime or during constant evaluation. A MapEntry is a fixed pair, so the factory has no capacity parameter.

Keys must support reliable, non-throwing equality comparison and non-throwing storage operations. Values must have a default value and be copyable, assignable, and destructible without throwing, so the entry remains safe to copy and update in bounded collections. Keys and values may themselves be cljonic collections or producers, including nested cljonic composites, provided they satisfy their respective constraints.

Key and value construction follows the safe implicit conversion rules.

Examples

#include "cljonic.hpp"
using namespace cljonic;
int main() {
// Compile-time demonstration.
constexpr auto m_const = hash_map(1, 100, 2, 200);
static_assert(first(m_const) == map_entry(1, 100) ||
first(m_const) == map_entry(2, 200));
// Explicit key and value types are available when deduction is not wanted.
constexpr auto e_explicit = map_entry<long, long>(1, 100);
// Runtime demonstration: a Map is created with hash_map and its entries,
// each a MapEntry value, can be traversed, compared, and added.
const auto m_runtime = hash_map<int, int, 4>(1, 100, 2, 200);
auto value_sum = 0;
for (const auto &entry : m_runtime) {
value_sum += entry.value;
}
const auto m_fuller = conj(m_runtime, map_entry(3, 300));
return (value_sum == 300 && m_fuller(3) == 300 && e_explicit.key == 1) ? 0
: 1;
}
