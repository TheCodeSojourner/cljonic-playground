Detailed Description

template<concepts_detail::RepeatClassArgument T>
class cljonic::Repeat< T >

A Repeat is a producer that owns one value and yields copies of it. The value may itself be a cljonic collection or producer, including nested cljonic composites. repeat(value) is unbounded, while repeat(count, value) yields exactly count values.

Observation is bounded by CLJONIC_COLLECTION_MAXIMUM_ELEMENT_COUNT_VALUE, by the requested count, or by an explicit destination capacity, and it supports const C++ range traversal in both constant evaluation and runtime code. Values can be passed directly to cljonic operations that accept a source, or converted into an owning destination with into when explicit materialization is required.

Values and finite counts follow the safe implicit conversion rules. Counts accept signed or unsigned integer types whose nonnegative ranges fit std::size_t, excluding Boolean and character types. Zero or negative counts produce an empty finite Repeat.

#include "cljonic.hpp"
using namespace cljonic;
struct Pixel {
int x{};
int y{};
friend constexpr auto operator==(const Pixel &, const Pixel &) noexcept
-> bool = default;
};
int main() {
// A finite Repeat yields the value exactly the requested number of times.
constexpr auto finite = Repeat{3, 7};
constexpr auto pixels = Repeat{2, Pixel{4, 9}};
// An uncounted Repeat is an unbounded producer.
[[maybe_unused]] constexpr auto unbounded = Repeat{7};
// -----------------------------------------------------------------------
// C++ interoperability: Repeat supports const traversal.
// -----------------------------------------------------------------------
auto runtime_finite = Repeat{2, -1};
constexpr auto finite_sum = [finite] {
auto sum = 0;
for (const auto value : finite) {
sum += value;
}
return sum;
}();
static_assert(finite_sum == 21);
constexpr auto pixel_sum = [pixels] {
auto sum = 0;
for (const auto pixel : pixels) {
sum += pixel.x + pixel.y;
}
return sum;
}();
static_assert(pixel_sum == 26);
auto runtime_sum = 0;
for (const auto value : runtime_finite) {
runtime_sum += value;
}
return runtime_sum == -2 ? 0 : 1;
}

template<concepts_detail::RepeatClassArgument T>
auto operator== ( const Repeat< T > & lhs,
const Repeat< T > & rhs ) -> bool
friend

Producer parameter equality (REQ-FN-014B): compares only the stored value, count, and finite-form parameters, never the produced sequence.

It is the only producer parameter-equality surface; the equal free function instead compares bounded logical observations of the produced sequences. The unbounded repeat(value) form is distinct from the finite repeat(count, value) forms even when their produced prefixes coincide, and a counted form with count zero is distinct from the unbounded form. O(1), no traversal, no allocation.
