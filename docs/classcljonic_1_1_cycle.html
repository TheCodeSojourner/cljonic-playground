Detailed Description

template<concepts_detail::CycleClassArgument Source>
class cljonic::Cycle< Source >

A Cycle is an unbounded producer over an owned source value, which must be a cljonic collection or producer. The source's elements may themselves be cljonic collections or producers, including nested cljonic composites. A finite source sequence is repeated from the beginning after exhaustion.

The only approved public form is cycle(source). It supports const C++ range traversal in both constant evaluation and runtime code. Values can be passed directly to cljonic operations that accept a source.

Observation yields at most CLJONIC_COLLECTION_MAXIMUM_ELEMENT_COUNT_VALUE elements.

#include "cljonic.hpp"
using namespace cljonic;
int main() {
[[maybe_unused]] constexpr auto finite_cycle = cycle(vector(1, 2, 3));
[[maybe_unused]] constexpr auto unbounded_cycle = cycle(Range{0, 0, 0});
// -----------------------------------------------------------------------
// C++ interoperability: Cycle supports const traversal.
// -----------------------------------------------------------------------
auto runtime_cycle = cycle(vector(4, 5, 6));
auto runtime_unbounded_cycle = cycle(Range{0, 0, 0});
// Use C++ interoperability to observe a finite source cycle at runtime.
auto runtime_sum = 0;
auto runtime_count = 0;
for (const auto value : runtime_cycle) {
runtime_sum += value;
if (++runtime_count == 5) {
break;
}
}
// Use C++ interoperability to observe an unbounded source cycle at runtime.
auto runtime_unbounded_sum = 0;
auto runtime_unbounded_count = 0;
for (const auto value : runtime_unbounded_cycle) {
runtime_unbounded_sum += value;
if (++runtime_unbounded_count == 4) {
break;
}
}
return runtime_count == 5 && runtime_sum == 24 &&
runtime_unbounded_count == 4 && runtime_unbounded_sum == 0
? 0
: 1;
}

auto operator== ( const Cycle< Source > & lhs,
const Cycle< Source > & rhs ) -> bool
friend

Producer parameter equality (REQ-FN-014B): compares only the stored owned source, count, finite-form, and starting-offset parameters, never the produced sequence.

It is the only producer parameter-equality surface; the equal free function instead compares bounded logical observations of the produced sequences. The owned source compares by its own stable equality, so cycle(vector(1, 2, 3)) == cycle(vector(1, 2, 3)) is true while cycle(vector(1, 2, 3)) == cycle(vector(1, 2, 4)) is false. O(1), no traversal, no allocation.
